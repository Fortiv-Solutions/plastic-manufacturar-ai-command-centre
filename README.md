# AI Command Center for Plastic & Polymer Manufacturing Sector

Enterprise AI Operating System for plastic and polymer manufacturing enterprises, powered by 63 AI agents and 306 zero-touch automations.

## Tech Stack
- **Framework**: TanStack Start / Vite
- **UI Components**: React 19 + Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **Language**: TypeScript

## Getting Started

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
```
